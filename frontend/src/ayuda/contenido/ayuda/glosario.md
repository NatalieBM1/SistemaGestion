## Términos

| Término | Significado |
|---|---|
| **Remisión** | Documento que registra un servicio de transporte: cliente, origen, destino, vehículo, conductor y productos. |
| **Prefijo** | Letras que identifican la serie de numeración de la remisión, por ejemplo GTS. |
| **Consecutivo** | Número que sigue en la serie del prefijo. Lo asigna el sistema en los prefijos automáticos. |
| **GTS** | Ejemplo de prefijo automático: el sistema asigna el número. |
| **GTM** | Prefijo manual (remisión de papel): el número lo escribe el usuario desde el talonario. |
| **Orden de servicio (ODS)** | Cupo en pesos aprobado por el cliente; el valor flete de las remisiones asociadas se descuenta de su saldo. |
| **Saldo de la orden** | Lo que queda disponible de la orden de servicio. |
| **Saldo pendiente** | Lo que falta por facturar de una remisión: valor total − facturado. |
| **Proyecto** | Obra o proyecto del cliente al que pertenece el servicio. |
| **Tramo** | Parte de un proyecto (por ejemplo un sector de una vía). |
| **Cama baja** | Remolque de plataforma baja para carga pesada. También aplica a trailer o volco. Tiene su propia placa y su propio valor. |
| **Producto** | Material o servicio transportado en la remisión, con cantidad, unidad y valores. |
| **Valor material** | Valor del material transportado. |
| **Valor flete** | Valor del transporte. |
| **Valor total** | Suma de valor material + valor flete + valor cama baja de todos los productos. |
| **Factura total** | Facturación por todo el saldo pendiente de la remisión. |
| **Factura parcial** | Facturación por una parte del saldo; la remisión queda **Facturada parcial**. |
| **Anular facturación** | Dejar sin efecto una facturación; queda en el historial como **Anulada** y el saldo se recalcula. |
| **Tercero** | Persona o empresa registrada: cliente, conductor, proveedor, empresa propietaria. |
| **Activo** | Vehículo o remolque registrado con su placa. |
| **Código DANE** | Código oficial de departamentos y municipios de Colombia. |
| **Rol** | Conjunto de permisos que se asigna a un usuario. |
| **m³** | Metro cúbico. |
